# Картыч — карта лояльности в MAX

Гость сканирует QR после покупки. Бизнес создаёт точку и программу (визиты → подарок). Кофейня была только примером сценария.


Сейчас сделан **этап 1: каркас в проде** — FastAPI, вебхук, эхо на `bot_started`, сторож `GET /subscriptions`, деплой на VPS с HTTPS.

## Что уже работает

- `POST /webhook` сразу отвечает `200`, обработка в `BackgroundTasks`.
- Событие `bot_started` (кнопка «Начать») — приветствие и кнопки: Старт / баланс / как это работает.
- `ping` в чат — ответ `pong`.
- Фоновый сторож раз в минуту бьёт в `GET /subscriptions` и заново подписывается, если URL пропал.
- Заготовки мини-приложения (`/app`, HTMX + Pico.css + QR) и дашборда (`/dashboard`, Plotly).

## Что прислать мне, чтобы включить на VPS

Токен в чат можно не писать: открой `.env` в корне и вставь сам. Если удобнее — пришли сюда, я пропишу.

**MAX**

1. `MAX_BOT_TOKEN` — токен бота из кабинета MAX → Чат-боты → настройки.
2. `MAX_BOT_USERNAME` — ник бота без `@`.
3. Скрин или подтверждение, что бот уже создан и (по возможности) прошёл модерацию.

**Домен и сервер**

4. Домен, который смотрит на VPS, например `cupcard.example.ru`. Без домена MAX вебхук не примет: нужен HTTPS и порт 443, самоподписанный сертификат не подходит.
5. IPv4 (и IPv6, если есть) VPS.
6. SSH: пользователь, порт если не 22, и либо пароль, либо ключ.
7. Что за облако: Timeweb / VK Cloud / Selectel / другое — чтобы я не угадывал панель.
8. Если DNS ещё не настроен — доступ в панель, где вешается A-запись на IP.

**Не обязательно сразу**

- Отдельные Postgres/Redis не нужны: они поднимутся в Docker на том же VPS.
- Почта для Let's Encrypt: можно `LETSENCRYPT_EMAIL`.
- URL мини-приложения в кабинете MAX пропишем после того, как домен заживёт: `https://ДОМЕН/app`. Там же кнопка открытия: «Старт».

## Локально

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
copy .env.example .env   # токен уже ждёт в .env
docker compose up -d postgres redis
alembic upgrade head
uvicorn app.main:app --reload --port 8000
pytest
```

Пока `PUBLIC_BASE_URL` не `https://...`, подписка webhook при старте не регистрируется — так и задумано.

## Прод на VPS

1. Домен → A-запись на IP.
2. Репозиторий и заполненный `.env` на сервере: `PUBLIC_BASE_URL=https://ДОМЕН`, `PUBLIC_HOST=ДОМЕН`.
3. `sudo bash deploy/setup-vps.sh`
4. Проверка: `https://ДОМЕН/health`
5. В MAX: Чат-боты → настройки → URL мини-приложения `https://ДОМЕН/app`, кнопка «Старт».
6. Открыть бота в MAX, нажать «Начать» — должно прийти эхо.

API MAX: `https://platform-api2.max.ru`. Авторизация заголовком `Authorization: <токен>` без Bearer.
